Project Overview

We decided to do a website for a car dealership. Our project includes five connected pages, Home, About, Contact, Registration, and Services
All five pages share the same general design, navigation, colors, fonts, and layout to create a consistent experience.

Our Development Work and Improvements

We used GitHub Copilot to help us build a template to build off of, and made adjustments as needed. All three group members worked together to review, edit, and improve the website. Changes were made to the individual HTML pages, corrected mistakes, improved the content, updated the styling, and made sure there was a consistent experience throughout the website.
